Kendali Robot & Pneumatik

Pin GPIO mengeluarkan sinyal HIGH (3.3V) ke modul Optocoupler/Relay 24V untuk menggerakkan silinder sortir.

Sinyal: HIGH (3.3V DC)

2. Perbandingan Mikrokontroler vs Jetson Orin Nano

Aspek Teknis Arduino / ESP32 NVIDIA Jetson Orin Nano
Arsitektur Prosesor Mikrokontroler (8/32-bit MCU) 6-Core Arm CPU + 1024-Core GPU
Kemampuan AI Sangat terbatas (TinyML dasar) 40 TOPS (Deteksi Objek Real-time)
Sistem Operasi Bare-metal / FreeRTOS NVIDIA JetPack (Ubuntu Linux)
Bahasa Pemrograman C / C++ (Arduino IDE) Python, C++, CUDA, ROS 2
Peran di Industri Baca sensor analog & kontrol motor lokal Otak Robot Otonom, Quality Control Kamera
Catatan K3 Elektronika: Tegangan GPIO 3.3V!

Pin GPIO pada Jetson Orin Nano bekerja pada level tegangan logika 3.3V DC dengan arus maksimal sangat kecil (~2 mA).

✖ JANGAN: Menghubungkan pin GPIO langsung ke sensor 5V/24V PLC atau koil solenoid/motor DC!
✔ WAJIB: Gunakan Optocoupler, Logic Level Shifter (3.3V ↔ 5V), atau Driver MOSFET/Relay untuk mengisolasi rangkaian daya industri 24V.

# Program Kendali Sortir Cacat Elektronik - Jetson Orin Nano
import Jetson.GPIO as GPIO
import jetson_inference, jetson_utils, time

REJECT_PIN = 18          # Sinyal 3.3V ke Relay Pneumatik
CONF_LIMIT = 0.75        # Batas keyakinan deteksi AI
AI_ACTIVE  = True        # Status akselerasi TensorRT

GPIO.setmode(GPIO.BOARD)
GPIO.setup(REJECT_PIN, GPIO.OUT, initial=GPIO.LOW)
net = jetson_inference.detectNet("pcb-qc-yolov8", threshold=CONF_LIMIT)

while True:
    frame = camera.Capture()
    detections = net.Detect(frame) if AI_ACTIVE else []
    for obj in detections:
        if obj.Class == "CACAT" and obj.Confidence >= CONF_LIMIT:
            GPIO.output(REJECT_PIN, GPIO.HIGH) # Aktifkan Lengan Sortir!
            time.sleep(0.15)
            GPIO.output(REJECT_PIN, GPIO.LOW)
